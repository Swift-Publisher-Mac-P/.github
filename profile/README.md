## Getting Clean Results

A little care up front makes swift publisher for mac far smoother to work with. The habits below head off the
frustrations people most often hit on their first few projects.

- **Start from a template** — open a matching design rather than a blank page, so margins and structure are already sensible.
- **Think in text boxes** — build stories in linked boxes so long copy flows correctly instead of overrunning one frame.
- **Set page size first** — choose the real print dimensions before laying anything out, so nothing shifts later.
- **Group before you move** — group related objects so a headline and its graphic travel together.

## Quick Fix Reference

Most sticking points in page layout mac work fall into a handful of familiar situations. Here's how to handle each.

| Issue | Fix |
|---|---|
| Text overflows a box | Link a second text box so the story flows into it, instead of shrinking the type |
| Copy overlaps a photo | Turn on text wrap so paragraphs flow neatly around the image |
| A design feels like a blank slate | Start from one of the built-in templates and customize it |
| An object won't move with others | Group the elements first, then drag them as one |
| A photo looks plain and boxy | Apply a creative mask to frame it in a non-rectangular shape |
| Colors don't match your brand | Tint the object and adjust its opacity to fit your palette |
